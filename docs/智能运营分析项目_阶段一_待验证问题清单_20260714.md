## 执行前置约束

1. 先备份或冻结当前 386 条 Git 工作区状态，记录准确文件清单和校验值；不得 reset/checkout 覆盖。
2. 生产/现有数据库只读；需要写操作的验证必须使用新建隔离库或事务可回滚的测试 schema。
3. 模型、预测、报告、知识库均使用新 run_id 和隔离输出目录，不覆盖 `model_artifacts`、`结果-3`、`自动化输出/current`。
4. 敏感配置只做 presence/权限验证，不打印值；外部 API 采用最小请求。
5. 不执行批量删除。需要清理时由用户逐项确认明确文件路径。

## 阶段二建议停止条件

遇到以下任一情况应停止写入型验证并向用户报告：

- 无法确认测试连接是否指向隔离数据库；
