# P6 UI 优化前必读统一 SKILL 使用说明

建议放置路径：

```text
.codex/skills/p6-ui-optimization-master/SKILL.md
```

或放在项目文档目录：

```text
docs/P6_UI优化前必读统一SKILL.md
```

每次让 Codex 或其他开发代理优化 UI 前，先把任务提示词改成：

```text
请先读取并遵守 p6-ui-optimization-master/SKILL.md，再根据本次页面读取目标参考图、差异分析文档对应章节和 P6 落地方案对应阶段，然后再开始修改。
```

本包把以下内容统一成一个入口：

1. UI 参考图与当前功能差异分析的阅读要求。
2. P6 UI 与功能排版优化落地方案的执行要求。
3. 布局、边界、等距、内容自适应、内部滚动、顶部空间利用、非全屏响应式等硬性要求。
4. mock/fallback/derived、真实数据、状态机、安全边界、验收门禁和 Codex 提示词模板。
