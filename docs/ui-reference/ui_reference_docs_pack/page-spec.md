# AI售电交易决策平台 页面功能规格说明

## 1. 总体页面结构

本项目包含 10 个核心一级页面：

1. 首页
2. 数据中心
3. 预测中心
4. 策略中心
5. AI助手
6. 报告中心
7. 模型中心
8. 知识库
9. 任务中心
10. 系统设置

页面整体使用统一 Layout。

```text
AI售电交易决策平台
├── 首页
├── 数据中心
├── 预测中心
├── 策略中心
├── AI助手
├── 报告中心
├── 模型中心
├── 知识库
├── 任务中心
└── 系统设置
```

## 3. 首页 Dashboard

### 3.1 页面目标

首页用于展示系统整体状态，帮助用户快速了解预测结果、风险、策略、报告和任务情况。

### 3.2 页面模块

顶部指标卡：

- 明日最高价
- 明日最低价
- 均价
- 峰谷价差
- 高价风险时段
- 低价机会时段

中部主视觉区：

- 浅色 3D 光伏电站 / 储能柜 / 电网节点示意图
- 光伏出力
- 储能 SOC
- 并网功率
- 运行状态
- 今日发电量
- 今日充电量
- 今日放电量
- 预计收益

底部业务区：

- 24小时电价趋势
- 储能充放电建议
- 最新报告
- 任务日志

右侧提醒区：

- 高价风险预警
- 模型误差提醒
- 数据延迟提醒
- 任务失败提醒
- 市场信息更新

### 3.3 关键交互

- 点击风险提醒，跳转策略中心。
- 点击电价趋势，跳转预测中心。
- 点击报告，跳转报告中心。
- 点击任务，跳转任务中心。
- 首页所有数据先支持 Mock 数据。

## 13. 页面交付验收标准

1. 所有页面能通过左侧菜单正常访问。
2. 所有页面保持统一 Layout、主题色、圆角、卡片风格。
3. 所有页面先使用 Mock 数据，不能依赖后端接口完成首版展示。
4. 所有图表使用 ECharts。
5. 所有接口调用必须封装在 `services` 目录。
6. 所有页面类型定义必须放在 `types` 目录。
7. 不允许所有页面堆在 `main.tsx` 中。
8. 需要支持 1366px 宽度下正常展示。
9. 需要运行 `npm run build` 通过。
