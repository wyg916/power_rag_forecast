## 实施约束

1. 客户端只能提交 `dataset_id` 与注册表允许的分页、过滤、排序参数。
2. 未注册数据集、字段、排序和过滤默认拒绝，管理员不得绕过。
3. 旧任意 SQL API 永久返回 410，输入不得到达数据库或进入日志。
4. 正常后端运行、敏感身份仓库和迁移使用不同数据库身份。
5. 正式 ACL 仅修改 `beta10d_` 项目角色及其对象权限，不修改业务数据或结构。
6. 数据库测试沿用 Day 3 一次性隔离 Schema/角色，或在真实运行账号事务内回滚。
7. 不实施报告真实性、预测闭环、Celery、RAG、依赖升级或无关 UI 重构。
