# 任务 17：Day1 唯一 RC 集成与一键启动闭环

## 目标

在不触碰主工作树用户改动、不执行生产切换和业务写入的前提下，建立唯一 RC，按白名单接入 Day8、RAG-R1 证据闭环与检索性能提交，并交付可复现的本地基础服务启动入口。

## 允许范围

- 创建独立 RC 分支/工作树和 E 盘检查点。
- 快进或 `cherry-pick -x` 白名单提交。
- 修复由白名单集成暴露的兼容性与启动器问题。
- 运行只读数据库检查、Python 测试、前端构建和本地健康验证。
- 更新全局规则、基线、RC 清单、运行指南、状态与证据。

## 禁止范围

- 修改主工作树未提交/未跟踪内容。
- 数据库迁移、Seed、同步、全表写入或不可逆操作。
- 模型反序列化、训练、注册、激活或生产切换。
- Qdrant alias/snapshot/release 发布。
- 外网调用、全局安装或自动联网安装前端依赖。

## 验收标准

- 唯一 RC 分支和白名单来源可追溯。
- Alembic 只有一个 head。
- 默认 `run_project.bat` 能完成前检、Redis、隔离 Celery、Web 两端和组合健康。
- 启动过程不执行同步、迁移、Seed 或未知进程终止。
- Python 目标回归、前端生产构建、HTTP 冒烟通过。
- 数据库只读快照写入计数为 0，RAG/模型状态未改变。
- 证据与回滚路径落盘，`TASK_STATUS.md` 更新。
