# P6 策略中心三子页面 UI 优化

## 目标

将策略中心收敛为三个可见、可切换且可独立路由的子页面：

1. 总览主页面；
2. 低价窗口与储能策略；
3. 人工复核。

视觉结构以 2026-06-21 三张策略中心参考图为目标，功能边界以当前真实 API、PHASE5-D 状态机和正式库事实为准。

## 范围

- 增加三页可见页签和稳定路由，旧低价窗口地址兼容映射到储能策略页。
- 优化总览、储能、人工复核三页的布局、筛选、指标和响应式表现。
- 复用真实预测、策略、配置、人工审核与审计 API。
- 保持批量审核、执行清单、已执行回填等未具备后端闭环的动作禁用，并显示明确说明。

## 禁止项

- 不伪造 SOC、执行清单、实际收益或批量审核结果。
- 不通过浏览器触发正式库策略提交、批准、驳回、退回或发布。
- 不改造预测模型，不新增交易、设备或资金执行能力。

## 验收

- 前端 TypeScript/Vite 生产构建 PASS。
- PHASE5-D 治理专项回归 PASS。
- 三页在 1920×1080、1440×900、1366×768 无页面级横向溢出。
- 页签、刷新、筛选、搜索、导出、配置弹窗、候选时段联动和单项审核入口完成浏览器验收。
- 控制台无 warning/error。
- 建立前置检查点、结果证据和可验证回滚路径。
