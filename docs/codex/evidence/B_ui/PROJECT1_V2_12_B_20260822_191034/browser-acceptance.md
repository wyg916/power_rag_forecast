## 全局助手与附件

- 全局悬浮按钮：32/32 业务路由可见；登录页不挂载。
- 右侧 Drawer：桌面 500px；小屏适配全宽；关闭、收起、新会话、停止生成、跳转完整 AI 页面均存在且可键盘访问。
- 跨页面保持：在首页填写未发送草稿并通过 Ctrl+V 加入 clipboard.png，跳转完整 AI 页面后，Drawer、草稿、附件和会话状态保持。
- Ctrl+V 图片：浏览器产生真实 File，前端生成缩略图并进入上传状态，PASS。
- 文件选择：多选、允许格式、状态、删除、失败后重试按钮均在浏览器实际验证。
- 拖拽：自动化源码契约验证 dragover/drop 与统一附件处理链路，PASS。

## 冻结契约集成依赖

冻结契约要求 POST /api/ai/attachments、GET /api/ai/attachments/{id}、DELETE /api/ai/attachments/{id}。当前后端仅有 POST；实际浏览器验证中 POST 上传成功，随后 GET 状态轮询返回 404，前端按契约显示 failed、重试和删除，没有静默伪造成 ready。GET/DELETE 属于后端所有权，未在本任务中越界补造。
