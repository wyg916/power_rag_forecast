# 策略中心三页 100% 缩放短屏适配复核

## 结论

本轮仍为独立人工评审版，尚未合入 `main`。针对用户指出的“全屏 100% 缩放无法完整显示”，新增 1280×720 与 1366×768 短视口高度预算，并逐层核对页面根、工作区、子卡片及表格的 `clientHeight/scrollHeight`，不再只检查文档级滚动。

## 修改范围

- `frontend/src/pages/strategy/strategy-center-layout.css`
  - 1181px 以上且高度不超过 820px 时压缩页头、KPI、间距与卡片内边距。
  - 总览页重新分配主图与四张底卡高度，保留完整建议、环图与收益说明。
  - 储能页按实际剩余高度重排图表/反馈表，设备清单和详情使用明确的卡片内滚动。
  - 人工复核页缩短底部摘要高度并压缩表格单元格，消除 1px 舍入造成的横向滚动条。
- `frontend/src/components/strategy/StrategyDesign.tsx`
  - 储能反馈表改为固定表格布局，七列在短屏内完整显示，保留“查看详情”。
  - 人工复核表保留八列、Tooltip、分页、“查看/复核”操作，移除短屏横向滚动依赖。
  - 复核表纵向滚动高度改为基于实际剩余高度的 `clamp`。
- 测试只同步新的布局预算与操作入口契约。

未修改后端、API、数据库、路由、权限、业务字段、审核动作处理函数或全局 AI 功能。
