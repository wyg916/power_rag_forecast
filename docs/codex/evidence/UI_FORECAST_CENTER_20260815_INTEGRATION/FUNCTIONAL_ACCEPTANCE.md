## 状态与错误门禁

- Loading、Empty、Error、Stale、Unauthorized、Forbidden 组件/契约测试覆盖通过。
- Stale：真实预测 run 已过业务窗口，页面仅保留中性业务状态，不展示用户要求移除的审计字段。
- Unauthorized：无身份请求返回 401。
- Forbidden：viewer 请求数据质量受限接口返回 403。
- 干净三页窗口 Console Error=0、Warning=0。
- 干净三页网络窗口 54 请求全部 HTTP 200；Unexpected 4xx/5xx=0；Traceback=0。
- 导航到目标范围外的报告审核页产生的 403 是预期权限行为，已从目标页干净网络窗口剔除，未冒充目标页异常。
