## 七态

| 状态 | 结果 | 验证方式 |
|---|---|---|
| Loading | PASS | 页面强制刷新时出现并最终退出“正在加载当前查询范围” |
| Empty | CONTRACT PASS | 七态和 Empty 分支定向契约测试通过；真实库当前非空，不伪造 Empty 数据 |
| Error | PASS | 错误状态保留 HTTP 状态/错误码和重试入口；定向契约测试通过 |
| Stale | PASS | API 返回 `is_stale=true`，页面以中性“需复核”呈现，不展示被禁止的过期审计文案 |
| Unauthorized | PASS | 不带身份请求 `/api/forecast/24h` 返回 401 |
| Forbidden | PASS | viewer 请求 `/api/data/quality` 返回 403 |
| Success | PASS | 三页真实数据、全部适用控件和刷新后状态通过 |

页面主内容中未出现：数据已过期、预测适用窗口已结束、生成时间、更新时间、run_id、模型版本、特征版本、预测日期、区域、数据源、推理模型、适用窗口、批次状态、异常原因。后端审计字段未删除。
