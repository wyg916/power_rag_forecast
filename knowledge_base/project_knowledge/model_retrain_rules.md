# 模型重训判断规则

模型是否需要重训不能只看一次误差变大。更稳妥的判断方式是观察连续多个预测窗口的 MAE、RMSE、峰时误差、异常价格覆盖、特征分布变化和业务影响。

如果误差集中出现在高价尖峰、极端天气或数据缺失时段，应先排查数据和特征问题；如果误差持续扩大且数据质量正常，再考虑重训、特征更新或模型版本切换。

## 适用问题示例

- 模型最近误差变大要不要重训？
- 重训前先检查什么？
- 模型漂移怎么判断？

## 回答要点

- 先看连续性、样本数和错误分布。
- 先排查数据新鲜度、真实值回填、天气负荷偏差。
- 重训需要评估新旧模型对比和回测指标。
- AI 助手只能给建议，不能自动判定生产切换。
