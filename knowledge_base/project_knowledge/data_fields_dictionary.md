# 项目数据字段字典

项目中的核心字段通常包括时间字段、预测电价、负荷、天气、风险等级、尖峰概率、模型版本、误差指标和数据来源。具体字段名称以数据库表和接口返回为准。

解释字段时要区分预测值、真实回填值和派生指标。预测电价用于前瞻判断，真实电价用于回测和误差评估，风险等级用于运营预警，尖峰概率用于识别重点复核时段。

## 适用问题示例

- predicted_price 是什么意思？
- risk_level 怎么理解？
- 尖峰概率和预测价格有什么关系？

## 回答要点

- 字段解释必须以当前接口或表结构为准。
- 预测字段不能当作已发生事实。
- 误差字段需要结合样本数和统计口径解释。
- AI 助手不应伪造不存在的字段含义。
