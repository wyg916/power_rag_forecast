# 模型误差解释

模型误差反映预测值与真实回填值之间的偏差。常见指标包括 MAE、RMSE、MAPE 等。RMSE 对大偏差更敏感，因此尖峰价格预测误差变大时，RMSE 往往上升更明显。

误差变大可能来自数据新鲜度不足、天气突变、负荷预测偏差、市场结构变化、异常价格、训练样本覆盖不足、特征漂移或模型版本不适配。误差分析不能只看单日，需要结合样本数、时段、价格区间和异常点。

## 适用问题示例

- 模型最近误差变大，可能是什么原因？
- RMSE 变高说明什么？
- 模型需要重训吗？

## 回答要点

- 误差变大要区分整体误差、峰时误差和异常点。
- 先检查数据回填、天气和负荷偏差，再判断模型重训。
- 样本数不足时不能草率下结论。
- 重训建议应结合连续误差、漂移、业务影响和模型版本表现。
