# PJM DOM 节点背景

DOM 通常指 PJM 市场中 Dominion 相关区域或节点口径。项目配置中使用 DOM 作为默认分析节点，适合围绕该节点开展负荷、天气、电价预测和交易风险分析。

DOM 节点电价受区域负荷、系统供需、输电约束、天气变化和 PJM 市场整体波动影响。对售电运营来说，DOM 节点预测结果应与客户负荷结构、合约电量、储能资源和风险偏好一起评估。

## 适用问题示例

- DOM 节点是什么？
- 当前项目为什么关注 DOM？
- DOM 节点电价风险怎么看？

## 回答要点

- DOM 是项目当前默认节点或区域口径。
- 节点价格需要结合本地负荷和天气解释。
- 如果用户问具体价格，应优先引用项目预测表和风险识别结果。
- 不应把 DOM 节点结论直接推广到所有 PJM 节点。
