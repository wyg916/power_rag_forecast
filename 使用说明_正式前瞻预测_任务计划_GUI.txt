智能运营分析项目使用说明

零、首次环境配置
1. 复制项目根目录下的 .env.example，重命名为 .env。
2. 在 .env 中填写 DB_PASSWORD 等本机真实配置。PJM_SUBSCRIPTION_KEY 可选，未填写时会默认从 Data Miner 2 公开前端配置自动发现 subscription key。
3. 如需新环境安装依赖，请运行：
   python -m pip install -r requirements.txt
4. 真实数据库密码不再写入代码或 llm_service_config.yaml；生产环境仍建议在 .env 中填写自有 PJM Key。
5. 一键启动 bat 已统一启用 UTF-8；缺少 .env 时会提示，并使用系统环境变量和安全默认配置。

一、你现在可以直接怎么用
1. 双击：
<项目根目录>\启动智能运营分析GUI.bat
2. 打开图形界面后，优先使用以下按钮：
- 更新数据并全流程
- 直接全流程
- 仅生成 AI 报告
- 预测并生成报告
- 创建/覆盖任务计划

二、各按钮的作用
1. 更新数据并全流程
先更新本地公开数据，再依次执行预测引擎、AI 摘要、Word 报告、结果归档。

2. 直接全流程
不更新数据，直接执行全流程。

3. 仅生成 AI 报告
不重新跑预测，只基于当前已有结果重新生成 Word 报告和归档文件夹。

4. 预测并生成报告
重新运行预测引擎，并生成 AI 报告与归档结果，但不刷新数据。

5. 模型盘点
重新扫描本机模型、显卡、内存和 Ollama 情况。

6. 创建/覆盖任务计划
把当前流程写入 Windows 任务计划，按设定时间自动运行。

三、输出结果放在哪里
默认总输出目录：
<项目根目录>\全流程预测结果数据存放

每次运行后，系统都会生成一个新的时间戳文件夹，例如：
20260330_160500_电价预测运行结果

该文件夹下通常包含：
1. 01_正式预测结果
2. 02_AI报告
3. 03_关键模型结果
4. 04_运行日志

其中最重要的文件是：
1. 未来24小时正式前瞻预测结果.xlsx
2. 电价智能分析综合报告.docx

四、如何修改结果输出目录
1. 打开 GUI
2. 在“总输出目录”输入框中选择新的目录
3. 点击“保存配置”
4. 以后新的运行结果会自动输出到新的总目录

五、当前“未来24小时正式前瞻版”是什么意思
1. 演示版
演示版不是严格意义上的真实未来预测，它主要用于展示流程是否跑通，通常基于历史已知完整特征去做最后24小时的模拟输出。

2. 正式前瞻版
正式前瞻版才是用于真实未来时点预测的版本。它会面向未来24个目标小时逐小时递推，并尽量使用预测时点真正可获得的数据。

正式前瞻版优先使用：
1. 已有历史真实数据
2. PJM 的未来负荷预测数据
3. 可获取的天气预报数据

如果未来真实值在预测时天然不可得，系统会使用安全代理特征，例如：
1. 历史同小时或滞后天气代理
2. 历史模式代理负荷
3. 历史实时价差代理

因此，正式前瞻版不是“全部基于未来真实实况值”，而是“基于预测时刻真实可得信息 + 合理代理特征”的正式预测口径。这才符合真实部署场景。

六、数据更新规则
当前数据更新不是每次全量重下，而是：
1. 读取本地已保存的数据
2. 只抓取缺失的最新增量时间段
3. 自动去重
4. 保留最近24个月窗口

也就是说，更新后你拿到的是：
在之前基础上，补齐到当前最新可获取的数据。

七、日志怎么看
1. GUI 下方日志框会实时滚动显示当前步骤
2. 状态栏会显示当前执行步骤和已耗时
3. 所有日志也会在运行结果文件夹和自动化日志目录中保留

八、任务计划怎么用
1. 在 GUI 中填写任务名称、执行时间、执行模式
2. 点击“创建/覆盖任务计划”
3. Windows 会按设定时间自动运行

推荐执行模式：
refresh_data
含义：先更新数据，再跑预测和报告，最适合日常自动运行。

九、如果只想看说明
GUI 中“打开使用说明”按钮现在会直接打开这个 txt 文件，不再打开 md 文件。
